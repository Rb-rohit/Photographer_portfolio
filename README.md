# Royal Lens Photography

A cinematic photography portfolio website designed for luxury weddings, destination celebrations, travel stories, and editorial portraits. The experience combines an editorial visual style with smooth motion, immersive image browsing, and clear paths for visitors to explore work and request a booking.

## Highlights

- Responsive luxury photography portfolio layout
- Hero section with showreel access and portfolio navigation
- Rotating image gallery and categorized portfolio filtering
- Image lightbox with photography details and camera metadata
- Interactive service cards for weddings, events, travel, and lifestyle photography
- Booking and consultation modal flows
- Testimonials, metrics, contact section, and responsive navigation
- Motion-based transitions and a floating back-to-top control

## Portfolio Description

**Royal Lens Photography** is a premium photography portfolio website built to showcase emotionally driven wedding, travel, event, and editorial imagery. It uses immersive galleries, elegant editorial layouts, interactive service discovery, and focused booking flows to turn a visual portfolio into a complete client experience.

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Motion for React animations
- Lucide React and React Icons
- Canvas Confetti
- ESLint

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Create a production build

```bash
npm run build
```

### Run lint checks

```bash
npm run lint
```

## Project Structure

```text
src/
  assets/       Images and image references
  components/   Page sections, galleries, and modal components
  data/         Portfolio and service content
  App.jsx       Main page composition and shared state
```
